# خارطة التنفيذ (من المواصفة §17)

قاعدة: لا نبدأ كل الوحدات بالتوازي قبل تثبيت نماذج البيانات الأساسية (الملكية، الصفقة، القيود).

| المرحلة | النطاق | الحالة |
|---|---|---|
| 0 | تثبيت المتطلبات (قوالب، قيم قانونية/ضريبية، حدود الموافقات) | مُهيّأ في إعدادات النظام وRBAC ✅ |
| 1 | الأساس التقني: Auth+MFA، RBAC، Audit، إعدادات الكيان، ترقيم المستندات، API/OpenAPI، PWA/RTL | مكتملة ✅ |
| 2 | CRM والكتالوج وقوائم الأسعار وحجب التكلفة | مكتملة ✅ |
| 3 | العروض (Snapshot)، الموافقات، الصفقات وأوامر البيع، طلبات المورد الصيني | مكتملة ✅ |
| 4 | الشحن، المواقع، فصل الملكية/الحيازة، المخزون، الأرقام التسلسلية، الجرد | مكتملة ✅ |
| 5 | المحاسبة المزدوجة، الأستاذ العام، الذمم، الفواتير، الدفعات، الصناديق والبنوك | مكتملة ✅ |
| 6 | الهندسة الطبية، محاضر التركيب والتشغيل، عقود الضمان، وتذاكر الصيانة | مكتملة ✅ |
| 7 | الوثائق والأرشفة، استخراج الذكاء الاصطناعي (AI Gateway) بالمراجعة البشرية، الإشعارات | مكتملة ✅ |
| 8 | التقارير ولوحات التحكم التنفيذية، تحليلات الأعمال، ومحرك التصدير (CSV) | مكتملة ✅ |

## تعريف الإنجاز لكل مرحلة
1. نماذج + migrations + قيود DB.
2. خدمات الأعمال (services) مع معاملات وidempotency حيث يلزم.
3. API مع صلاحيات على مستوى الإجراء/السجل/الحقل.
4. اختبارات وحدة وتكامل وRBAC.
5. واجهة (عربي RTL أولاً) + توثيق OpenAPI.
