# التقدم

## المرحلة 1 — الأساس التقني ✅ (checkpoint)
- Backend: Django 5.2 + DRF، إعدادات بيئة، PostgreSQL 17، Argon2.
- الهوية: مستخدم مخصص (بريد)، JWT مع تدوير وإبطال، قفل الحساب بعد محاولات فاشلة (يستمر رغم الخطأ)، MFA/TOTP.
- RBAC: سجل صلاحيات `module.resource.action` + أدوار قابلة للتعديل + قوالب الأدوار العشرة.
  - `superuser` لا يتجاوز الصلاحيات؛ مدير النظام بلا `approve/post` تلقائياً (§9).
- التدقيق: `AuditEvent` غير قابل للتعديل/الحذف في التطبيق **وبمشغّل PostgreSQL**.
- إعدادات الكيان الواحد + ترقيم المستندات بقفل صف (بلا تعارض).
- أخطاء API موحدة مع `trace_id`، ترقيم صفحات، OpenAPI: `/api/docs/`.
- Frontend: Vite + React + TS، PWA (الـ API لا يُخزَّن مؤقتاً)، RTL/LTR حقيقي (عربي افتراضي)، دخول + MFA، قوائم حسب الصلاحية، المستخدمون، سجل التدقيق.
- الاختبارات: 13 backend + 2 frontend ناجحة.

## الديون المعروفة (تُعالج قبل الإنتاج)
- تشفير `mfa_secret` في قاعدة البيانات (حالياً نص عادي).
- تخزين التوكنات في sessionStorage → النظر في httpOnly cookies.
- CI/CD وحاويات (Docker) وبيئات staging/production.
